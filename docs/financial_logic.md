# Institutional-Grade Financial Logic

The core value of an enterprise ERP lies in the absolute accuracy and auditability of its financial engine.

## 1. The Double-Entry Engine

Every financial transaction must balance. The system enforces the fundamental accounting equation:
`Assets = Liabilities + Equity`

### 1.1 Atomic Transactions

When a transaction occurs (e.g., paying an invoice), the system must execute the corresponding ledger entries atomically.

**Example: Paying a $500 Supplier Invoice in Cash**

1.  **Debit:** Accounts Payable (Liability decreases) - Amount: +$500.00
2.  **Credit:** Cash Account (Asset decreases) - Amount: -$500.00
3.  **Validation Check:** `Sum(Lines) == 0`. (500 + -500 = 0).
4.  If the sum is not zero, the database transaction rolls back immediately.

## 2. Reconciliation Integrity

*   **Soft Closes:** Accounting periods can be 'soft-closed', preventing new entries for that period from unauthorized personnel, while allowing the Controller to make final adjustments.
*   **Hard Closes:** Once a period is audited and finalized, it is 'hard-closed'. The system rejects *all* write operations to transactions within that date range.
*   **Bank Reconciliation:** The system matches external bank statements against internal cash ledger entries, highlighting discrepancies for manual review.

## 3. Reporting Logic

Financial reports are generated by querying the immutable `ledger_lines`.

*   **Trial Balance:** Sums all debits and credits for every active account over a specified period. The grand totals must match perfectly.
*   **Profit & Loss (Income Statement):** Aggregates activity only for accounts of type 'REVENUE' and 'EXPENSE' over a specific period.
*   **Balance Sheet:** Calculates the current balances of 'ASSET', 'LIABILITY', and 'EQUITY' accounts up to a specific date.

## 4. Multi-Currency and Tax

*   **Base Currency:** The ERP maintains a single base currency for corporate reporting.
*   **Exchange Rates:** Foreign currency transactions record the original amount, the exchange rate at the exact time of the transaction, and the converted base currency amount.
*   **Tax Engine:** Automatically calculates jurisdiction-specific taxes (VAT, GST, Sales Tax) based on vendor location, item category, and shipping destination, automatically routing the tax amounts to the correct tax liability ledger accounts.
